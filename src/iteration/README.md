# 每日自迭代批（EvoAlphaDailyIteration）

> 22:00 计划任务的内核。把「选手学习资料」的当日增量，确定性地转为知识卡片、画像、
> 提案与影子回归证据；**参数类过门槛才生效，规则/代码类永远等人工确认**。

## 一句话职责

```
选手学习资料  →  知识卡片库  →  选手画像（机读版）  →  提案  →  影子回归
                     ↑                                        ↓
                资料哈希清单                              参数门禁（过门槛才生效）
```

## 运行

```powershell
cd yaoban-system
python scripts/daily_iteration.py --market-codes 1200 --market-cap 3000
```

产物与人读入口见 `../../docs/RUNBOOK.md` §每日自迭代批。**先看** `outputs/iteration/<date>/digest.md`。

## 模块边界

| 模块 | 职责 | 不做什么 |
|---|---|---|
| `sources.py` | 资料哈希清单与增量判定 | 不解析内容、不改资料目录 |
| `cards.py` | 卡片 Markdown 确定性解析 + 累加去重 | **不产生新结论** |
| `profile.py` | 机读画像 + 版本差异 | 不写叙述型画像（那由会话侧维护） |
| `rules.py` | 卡片 → 可执行信号表达式 + 参数网格 | 不做语义判断、不调用 LLM |
| `market.py` | 日线读取与前向收益口径 | 不写行情、不改数据源 |
| `shadow.py` | 案例归因回归 + 市场影子盘 | 不合并两类口径冒充前向绩效 |
| `gate.py` | 参数门禁（五项门槛 + 逐项明细） | **不写参数文件** |
| `intraday.py` | 分时规则层（均价线一票否决等），依赖本地 1m 快照 | 不联网、不猜数据 |
| `proposals.py` | 提案挖掘（参数轴 + 卡片缺口） | 不执行提案 |
| `reports.py` | 人读摘要 | — |

## 分钟数据管线

分时级规则（`testability=intraday` 的卡片）需要分钟数据，F 盘快照停在 `2026-08-25`，
已改为**按需本地快照**：

```powershell
python tools/snapshot_minute.py --from-case-table --freq 1m --since 2026-08-20
python tools/snapshot_minute.py --verify           # 校验覆盖度
```

快照落在 `data/minute/<freq>/<code>.parquet`（+ `.meta.json` 记录来源与拉取时间），
由 `src/iteration/intraday.py` 消费。已实测：32 只案例标的 1m 覆盖 2026-08-20 起。

**分时规则首个结果（含证伪）**：「分时跌破均价线 → 一票否决」（KC-0005）在 7 个交易日
18 条**选手明示**决策上准确率 **94.4%**（否决 6/6、买入存活 11/12；口径 09:35–10:00、
连续 5 分钟、tol 0.3%，由 108 组网格选出后**冻结不再调参**）。

但全市场反事实检验（`tools/run_intraday_counterfactual.py`）给出**相反**结论：

| 样本 | 被否决组 | 通过组 | 差值 | Welch p |
|---|---|---|---|---|
| 全市场 5,308 事件 | 均值 **1.093%** | 均值 **0.471%** | **−0.622pp** | 0.00014 |

**被否决的样本反而涨得更多。** 该纪律复刻了选手的行为与心理偏好（规避回撤路径不适），
但**不筛选收益**。据此已加入门禁 `gate.intraday_rule_verdict()`：
分时规则必须同时通过「反事实方向为正」与「统计显著」，**"命中率"不再构成晋级理由**。
详见 `../../docs/ITERATION_2026-09-11.md` §六。

## 出厂硬边界（改代码前必读）

1. **变更三分**：`parameter`（可自动生效）/ `rule`·`code`·`data`（恒 `pending_confirm`）。
   自动生效只写两处：`outputs/iteration/ledger.jsonl`（append-only 台账）与
   `<date>/parameter_patch.json`（补丁**预览**）。`config/parameters.toml` 由人工改。
2. **未量化不进自动化**：卡片 `testability=qualitative` 或 `quantified` 为空时，只出
   rule 类提案，绝不猜阈值（对齐蓝图 §9「禁止语义猜测标签」）。
3. **样本量前置**：候选 < 30 事件 / 基准 < 20 事件 / 窗口 < 20 交易日 → `insufficient_evidence`，
   既不算通过也不算否决，必须在摘要里显式可见。
4. **单轴搜索**：影子回归只做「基准 + 每次一个参数」的对比（`single_axis_variants`），
   不做全网格择优——全网格最优常是联合拟合噪声，且归因不可审计。
5. **失败可见**：数据缺口、行情未推进、规则异常一律写进摘要，不静默吞掉。

## 门禁阈值（`gate.py` 顶部常量）

自动生效需**同时**通过：

1. **样本量**：候选 ≥30 事件、基准 ≥20 事件、窗口 ≥20 交易日（不满足 → `insufficient_evidence`，
   既非通过也非否决）。
2. **质量不退化**：平均收益退化 ≤1pp。
3. **尾部风险**：P10 收益退化 ≤1pp。
4. **绝对可用性（地板）**：候选胜率 ≥50% **且**候选总收益（n×均值）> 0。
   —— 这一条独立于相对比较，任何路径都不能绕过：**从「很亏」到「没那么亏」不算改善**。
5. **改善路径**：质量路径（胜率 +1pp 或均值 +0.5pp）或容量路径（容量 ×1.15 且胜率退化 ≤5pp），
   且**总收益不得变差**（×≥1.0）。
6. **分段稳定**：两段各 ≥10 事件，且任一段均值退化 ≤1pp。

**改这些常量就是改门禁本身**，属 rule 类变更，需人工确认。

> ⚠️ 门禁做的是**单轴、其余不变**的推断，回答的是「这个阈值该调吗」，
> **不回答**「这套战法能不能赚钱」。后者要看影子盘与后续前向影子记录，两者不可混读。

## 测试

```powershell
python -m unittest tests.test_daily_iteration -v
```

覆盖：涨停口径（分板块）、信号确定性与单调性、卡片解析与缺字段跳过、
门禁六类判定（含 `insufficient_evidence` 与分段不稳定）、前向收益止损口径。

## 当前口径缺口（诚实标注）

- **分时规则已可编码但判定为「不予晋级」**：「跌破均价线不玩」（`KC-0005`）与选手行为
  吻合度 94.4%，但全市场反事实检验显示被否决组收益**更高**（+1.093% vs +0.471%，p≈0.0001）。
  结论：它是选手的行为特征，不是 alpha 来源。
- **历史窗口偏短**：`daily_rebuilt` 中位 141 根 bar（2026-02-11 起），
  MA60 等长周期指标预热后有效样本有限；`daily_tencent` 有约 305 根但只覆盖约 300 只且停在 08-28。
- **涨停回踩的「倍量柱」口径**：原实现硬编码 2×MA5(V)，实测过严（案例 605006 涨停柱仅 1.33×），
  已提为显式参数 `volume_surge_min` 交由影子回归校准。**当前该战法影子盘为负**
  （总收益 −23.5%、胜率 23.8%），参数层修不动，需按案例重定义形态（见提案 P109）。
