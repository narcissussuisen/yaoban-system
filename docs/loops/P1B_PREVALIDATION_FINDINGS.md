# P1-B 预验证：封单强度 × 修复后次日收益（2026-08-26）

## 数据
- 旧 L2 三天涨停样本 72 个（8/21/24/25），全部有次日收益（TDX 日线回填）
- 封单强度 = 收盘申买量1（买一量，股） / 当日成交额（相对强度，量纲无关）
- 次日收益 = 修复后口径（T+1 收盘 / -5% 止损，LOW 判定 + 开盘跳空按开盘价）

## 结果
| 封单强度 | n | 次日均值% | 胜率% |
|---|---|---|---|
| 低（≤中位） | 36 | +0.10 | 42 |
| 高（>中位） | 36 | **+0.97** | 44 |
| 差值 | | **+0.87pp** | |

## 解读
1. **封单强度与次日收益正相关（+0.87pp）**：封单强 = 资金认可度高 → 次日溢价延续
2. 与 P1-A 预验证的 ba_ratio 发现相互印证（承接强的票次日更好）——**"承接质量"在隔日维度是正向因子**
3. 与"恐慌衰竭"（当日维度）形成完整画像：
   - **当日**：恐慌衰竭点超跌反弹最优（+3.43%）
   - **隔日**：承接强/封单强延续最优（+0.97%~+1.57%）
   - → 两个子模式分治：当日做 T（恐慌衰竭）vs 隔日接力（封单质量）

## 局限
- 72 样本 3 天，不显著；方向性证据
- 封单强度用"买一量/成交额"代理（无流通市值数据），正式论证用"封单/流通市值"更标准
