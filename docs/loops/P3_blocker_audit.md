# 基线口径审计（P3 评审阻断项）—— 2026-08-26

## 结论：R3 打板基线存在系统性实现缺陷，四年证据需重出

## 缺陷（P3 评审逐笔重算发现 + 本机独立重算确认）
1. **止损判定误用 HIGH(r[3]) 当 LOW(r[4])**：daily 行结构 [sym,date,open,high,low,close,vol,amt]，
   `float(r[3]) <= stop_px` = "全天最高价低于止损价"才触发 → 止损几乎从不触发
   （影响 backtest_daban.py 与 backtest_market.py 所有档位）
2. **幻影成交**：止损触发日按止损价成交，但真实可达价=当日开盘价（跳空低开时低 8-12.6pp）
3. **退出日**：T+2 退出符合 A 股 T+1 约束（T+1 买入当天不可卖），但文档写"T+1 收盘卖"——文档表述错误，实现正确
