# ⚠️ 系统级证据失效通告（2026-08-26，P3 阻断项）

## 一、发生了什么
P3 止损评审（subagent）在复核"-3% 止损建议"时，发现回测引擎存在**系统性实现缺陷**，
并经独立重算确认：**此前全部模式的正期望结论建立在 bug 之上**。

## 二、缺陷（三个）
1. **止损判定误用 HIGH(r[3]) 当 LOW(r[4])**：日线行 [sym,date,open,high,low,close,...] 中
   r[3]=high。`high <= 止损价` 才触发止损 = "全天最高价低于止损价"——**止损几乎从不触发**
   （除全天崩溃日）。影响：backtest_daban.py / backtest_market.py / pullback_b2_test.py 全部档位。
2. **幻影成交**：触发日按止损价成交，但真实可达价 = 当日开盘价（跳空低开时平均低 8-12.6pp）。
3. **文档口径错位**：文档写"T+1 收盘卖"，实现为 T+2 退出（T+1 买入当天不可卖，T+2 正确，
   但报告标注错误）。

## 四、结论
- **R3 打板基线（已定型）作废**；动量池定稿作废；组合级（+560%/+713%）作废
- 修复后仅 2026（强市）为正：5+ +1.27%（不显著）、动量 +0.93%（显著）
- **没有任何模式通过"两年正期望"验收**——2025 年全线为负

- 这不是参数问题，是"回测引擎失真"——修复后真实期望远低于此前认知
