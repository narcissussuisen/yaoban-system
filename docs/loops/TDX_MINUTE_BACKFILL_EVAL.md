# TDX 分钟回填可行性评估（2026-08-26）

## 结论：暂缓直接回填 F 盘（单位不一致风险），列为工程选项

## 测试发现
- TDX get_security_bars(8=1min, 800根) 覆盖 8/21 13:41 至 8/26——**可补 8/24-8/26 缺口**
- 但单位不一致（600000 实测）：
  - volume：F盘 331,794 vs TDX 198,027（比值 1.68，非整数——TDX 可能按笔/手混合）
  - amount：比值约 6.7（口径不同）
  - 8/21 只从 13:41 开始（800 根上限截断，前 3 天半）
- 前复权：TDX 为不复权价（adj_factor=1），F 盘为前复权——近期无分红时近似，但有除权日则错

## 风险评估
- 直接 append 到 parquet_qfq_2026 会污染 QFQStore 缓存（需失效 + 单位换算 + 复权核对）
- 回测（动量池/5+打板）对 volume/amount 敏感（amt20 过滤）→ 单位错误会静默改变结果
- **收益计算只依赖 OHLC（已核对一致），若仅用于"扩展回测日期"可只补 OHLC+空 volume**——但违背数据完整性

## 决策
- **暂缓**：当前回测数据止于 8/21 可接受（P0 结论不受影响——样本外验证已用 2023-2026）
- P1 需要的是 tick 级（每日采集已就绪），分钟回填非必需
- 若未来需要"最新日回测"：用 daily 回填库（已核对 0 差异）做日线级验证，分钟级待 TDX 单位问题解决

## 备注
- TDX 日线回填（daily/）已验证 0 差异（259 重叠日）——日线级扩展安全
- 1min 数据仅用于 P1 因子当日验证（tick 采集），不依赖 TDX 历史分钟
