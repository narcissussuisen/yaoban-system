## 二、人工确认执行流程（基板核心）
1. 盘前 8:50: plan_daily 出计划(情绪/主线/备选≤4只跨方向) → 操盘手人工复核
2. 盘中: tick守护(持仓秒级, 止损/炸板自主, 破线减半自主, 连板保护) + scan提醒(全市场) + monitor(备选) + 止盈提醒(6%达标)
3. **人工确认点**: 新仓买入信号(scan/monitor 触发) → 操盘手看盘确认(盘口/分时强度) → 执行
4. 盘后 15:40: 收盘流水线(决策重建→记账→估值→归因→日报→迭代提案)
5. 17:00: 日线库增量重建 → 次日计划循环

## 四、风控红线（不可逾越）
- 单票 ≤45% 净值(2仓模式) / 毛敞口 ≤90%
- 单日回撤 ≥-5% → 次日仓位降档50%(熔断)
- 冰点日(dt>zt且zt<40) → 20%仓位档
- T+1 锁定(当日买入不可卖)
- 科创板/北交所/ST 永不参与
