# 妖板操盘手系统 · 优化路线图 v2

> 2026-08-28 · 从「批处理工具」到「实时操盘手」的全面升级

## 诊断：三个致命缺口

| 缺口 | 现状 | 职业操盘手标准 | 后果 |
|---|---|---|---|
| 感知盲区 | 5 分钟时延 + 只盯 8 只 | 秒级盯持仓 + 全市场异动实时扫描 | 做T收益源丧失；盘中模式机会全部错过 |
| 自省缺失 | 当天做了什么/模式成效/数据流动/迭代方向——一无所知 | 每日操作流水/模式绩效/符合度审计/迭代建议 | 无法从交易中学习，模式不进化 |
| 身份未转 | 被问才动，批处理模式 | 主动日循环：盘前→盘中→盘后→迭代 | 不是操盘手，是答题机器 |

## 阶段一：盘中感知网络（核心，约2天）

**目标**：从「5分钟盯8只」到「秒级盯持仓 + 分钟级扫全市场 + 实时分时确认」

### 1.1 持仓秒级监控（做T收益源）
- 每 5 秒拉持仓逐笔成交 → 重建分时图 → 实时评估：
  - 做T触发（分时远离均价线≥1.5% → T进/T出提示）
  - 卖出触发（止损/炸板/破均价线/乖离/次高点/KDJ死叉——12触发秒级检查）
  - 盈亏实时（浮盈/浮亏/距止损价距离）
- 触发 → 立即执行（ledger记账）+ 看板实时刷新 + 日志置顶

### 1.2 全市场异动扫描（模式之眼）
- 每 1 分钟扫全市场：涨幅/量比/换手/涨停状态 → 异动池（约30-80只）
- 异动池上跑选手模式粗筛（形态+板块热度+连板气质）→ 确认队列（约5-15只）
- 确认队列标的拉 1m 分时 → 三引擎逐bar评估 → 触发则建仓
- 这是「盘中在所有股票中找模式标的→分时找买点」的机械复刻

### 1.3 板块轮动监测
- 每 1 分钟计算各板块涨幅/涨停数/资金占比 → 主线切换信号
- 持仓板块强度变化 → 板块退潮提前预警
- 热度上升板块 → 注入异动池粗筛权重

### 1.4 盘中提醒网络
- 触发事件 → 写入 outputs/intraday/live_alerts.json
- 看板 30 秒自动刷新读取 → 顶部滚动提醒条
- 紧急事件（止损/回撤熔断）→ 日志标红 + 看板弹窗

**阶段一验收**：盘中任意时刻，我能回答——持仓什么状态？市场异动什么？有没有模式标的出现？做T机会在哪？

## 阶段二：交易员自省层（约1.5天）

**目标**：从「一问三不知」到「操作流水/模式绩效/符合度审计/迭代建议全自动」

### 2.1 当日操作流水（实时累积）
- 每笔交易：时间/标的/方向/数量/价格/触发规则/模式标注/符合度（符合或偏离+原因）
- 盘中实时写入 → 看板操作记录区实时刷新

### 2.2 模式绩效仪表（盘后自动）
- 各模式触发数/胜率/平均盈亏（fills按模式分类统计）
- 做T次数/成功率/差价贡献（t_buy/t_sell配对统计）
- 买入点分布与绩效（B点/抄底/回踩低吸 各占比）
- 卖出触发分布与绩效（12触发各占比）
- 与选手对照（方向一致性/集中度/收益差距）

### 2.3 盘中数据流动摘要（盘后自动）
- 当日异动 Top10（涨幅/量比/换手）
- 板块轮动轨迹（早盘→午盘→尾盘）
- 情绪温度变化曲线（开盘/午盘/收盘）
- 涨停梯队与炸板率演变

### 2.4 模式符合度审计（盘后自动）
- 每笔标注：完全符合 / 部分偏离（哪条规则）/ 严重偏离（不该做）
- 偏离原因分类：冲动/过度交易/止损迟延/追涨/模式外标的
- 修正建议：从偏离中产生具体规则修改提案

### 2.5 模式迭代建议（盘后自动→人工确认）
- 从绩效+偏离中自动生成迭代提案 → 写入 outputs/iteration_proposals/  → 人工确认后生效

**阶段二验收**：每天收盘后我能回答——今天每笔为什么做？模式哪个有效哪个失效？偏离了什么？明天怎么调？

## 阶段三：看板升级（约1.5天）

**目标**：从「空壳展示」到「操盘手的指挥中枢与复盘依据」

### 3.A 盘中实况区（优先）
- 持仓实时状态卡（秒级：现价/浮盈亏/距止损/做T提示灯）
- 异动 Top 滚动条（1分钟刷新）
- 实时操作流水（触发即追加）
- 板块热力图
- 触发提醒条（买/卖/T/止损/异动/板块切换）

### 3.B 交易员自省区
- 操作流水表（含符合度标注列）
- 模式绩效仪表盘（各模式胜率/盈亏条形图）
- 做T统计（次数/成功率/差价贡献）
- 符合度审计（偏离记录+原因）
- 迭代建议（最新提案）

### 3.C 组合进度区
- 组合净值 vs 选手 6.4× 进度条（双线+进度条）
- 回撤曲线 + 最大回撤标注
- 关键指标卡：累计收益/胜率/盈亏比/夏普/最大连亏/日均交易笔数
- 与选手对照表（同期收益/仓位/操作笔数/方向一致性）

### 3.D 做T点位分布升级
- 秒级精度（逐笔重建分时，T进/T出精确到秒）
- 差价统计（每笔T的进出差价/数量/利润）
- 当日T贡献度（T利润/当日总盈亏）

**阶段三验收**：打开看板=打开操盘手指挥中枢——盘中实况一目了然，盘后复盘有据可查，进度对标清晰可见。

---

## 阶段四：模式自迭代（约2天，持续）

**目标**：从「静态规则」到「每日学习进化的模式」

### 4.1 每日模式绩效→规则迭代
- 盘后自动统计各模式/参数当日绩效
- 连续N日低于阈值 → 自动生成参数调整提案
- 提案经回测验证（历史30日窗口）→ 人工确认 → 生效

### 4.2 选手信号对照学习
- 选手信号自动存档 → 每日对照（选股方向一致性/收益差距）
- 差距归因 → 模式修正方向

### 4.3 偏离→模式修正
- 偏离累积 → 识别系统性偏差（总是追涨/总是止损迟延）
- 生成针对性规则修正

### 4.4 新模式发现
- 异动池中未被现有模式捕捉但后续走强的标的 → 识别新形态
- 人工标注 → 形态提取 → 回测验证 → 纳入模式库

**阶段四验收**：系统每天比昨天更聪明——参数进化、偏离减少、与选手差距缩小。

## 日循环全景（升级后）

```
06:30  外盘快照（pull_global）
08:50  盘前计划（premarket：外盘+情绪+主线+备选+卖出清单+仓位档）
09:15  集合竞价观察（竞价冷热/低开高开 → 计划微调）
09:30  盘中感知网络启动
       ├ 持仓秒级监控（逐笔→分时→做T/卖出触发→执行+记录）
       ├ 全市场异动扫描（1分钟→异动池→模式粗筛→分时确认→建仓）
       ├ 板块轮动监测（主线切换/退潮预警）
       └ 实时提醒（看板刷新+日志+紧急弹窗）
15:00  盘中感知网络停止
15:40  收盘流水线（回填→全天重建→记账→净值→看板→归因）
16:00  交易员日报（操作流水+模式绩效+符合度审计+迭代建议）
16:30  tick采集（涨停池/L2快照积累）
17:00  模式迭代（绩效分析→提案→回测验证→确认生效）
17:30  次日预案草稿（基于今日归因+迭代结果）
```

## 优先级与依赖

```
阶段零（数据源） → 阶段一（感知网络）→ 阶段三A（盘中实况看板）
                      ↘ 阶段二（自省层）→ 阶段三B（自省看板）
                                          ↘ 阶段四（自迭代，持续）
                                          ↘ 阶段三C（进度看板）
```

- 阶段零是前置（无数据源则一切空谈）
- 阶段一+三A 最紧急（解决感知盲区——你批评的核心）
- 阶段二+三B 第二优先（解决自省缺失）
- 阶段三C+阶段四 持续进化（身份转换的长期闭环）

## 验收标准（终极）

1. 盘中任意时刻我能自主回答：持仓状态/市场异动/模式机会/做T机会/风险敞口
2. 每日收盘后《交易员日报》自动产出：操作流水/模式绩效/符合度/迭代建议
3. 看板=操盘手指挥中枢（盘中实况+盘后复盘+进度对标三合一）
4. 模式每日进化（参数调整有据可查、偏离减少、与选手差距缩小）
5. 我不再需要你推一下才动——日循环全自动运转，你只看板+给指导
