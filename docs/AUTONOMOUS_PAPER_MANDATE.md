# 逐妖交易团队自主模拟盘运行章程

> 生效日期：2026-08-31  
> 账户性质：本地模拟盘，不接入真实券商，不涉及真实资金  
> 汇报渠道：飞书机器人；webhook 仅保存于仓库外受限秘密文件

## 1. 职责

交易团队负责市场研究、行业与事件研究、候选筛选、模拟买卖、持仓监控、确定性减险、盘后复盘与规则迭代。用户负责持续提供妖板选手操作、交割记录、截图、视频与心得。新材料先进入只读证据库和影子实验，不直接覆盖生产规则。

Vibe Research 只提供有来源、可追溯的研究事实和候选线索；妖板系统根据确定性规则形成模拟订单。研究模型不得绕过台账、成交和风险门禁。

## 2. 账户授权

| 项目 | 规则 |
|---|---|
| 起算日 | 2026-08-31 |
| 初始资金 | 100,000 元，空仓 |
| 模式 | autonomous_paper |
| 基准 | 中证1000（000852.SH） |
| 范围 | 沪深主板、创业板 |

| 回撤暂停 | 相对历史峰值回撤达到 10%，停止新仓并审查 |
| 回撤终止 | 相对历史峰值回撤达到 15%，终止本轮模拟 |

## 3. 成交纪律

- 新仓只允许 autonomous_paper 且 require_human_decision=false 的账户执行。
- 信号使用触发后的下一根 1 分钟 K 线开盘价；一字涨停或无法证明成交时不成交。
- 买入按 100 股整手向下取整，下一分钟成交量参与率不超过 5%。
- 台账再次强制检查现金、单票权重、总敞口、持仓数和每日新仓数。
- 卖出遵守 T+1；跌停、无量或无可卖数量时只告警，不虚构成交。
- 止损、炸板和破 VWAP 减仓由秒级守护执行，且仅允许自主模拟账户。
- 做 T 在生产环境暂为影子模式。当前已有规则、回放和台账函数，但尚无通过生产门禁的盘中执行器；完成专门测试前不得记为自主成交。

## 4. 数据失效

关键行情、交易日历、计划、台账或服务健康检查失败时禁止新仓。备用源只有在日期和一致性校验通过后才能接管。确定性减险只在所需输入完整时执行。所有失败、降级、拒单和未成交原因进入审计记录。

## 5. 汇报

- 08:50：盘前计划、市场温度、候选和风险纪律。
- 盘中：新模拟成交、风险事件、数据失效和任务失败；相同事件按幂等键去重。
- 15:40 后：净值、现金、持仓、成交、熔断状态和复盘摘要。
- 通知失败不放宽风控，不阻止本地审计落盘；任务失败保持 fail-closed。

## 6. 评价

首月用于初筛，三个月用于确认正期望。并行报告：相对中证1000超额收益、成本后绝对绩效、最大回撤、成交与审计完整性，以及与妖板选手同期轨迹的差距。选手记录是学习锚和对照基准，不是一票否决门槛。
