## R2 量化专家评审机制 ⏳

- 每阶段末启动 subagent（量化专家角色）：审查方法严谨性（前视偏差/幸存者偏差/成本口径/参数过拟合/样本外一致性）
- 评审结论写入 docs/reviews/{stage}_{date}.md，明确「通过 / 有条件通过（列整改项）/ 不通过」
- 不通过或有条件通过 → 整改后复审；评审记录作为合入的强制前置

## 执行原则（loop engineering）

1. 每阶段：假设 → 数据验证 → 定稿 → **专家评审** → 合入/否决，结论全部入档
2. 小样本结论必须先过信号级大样本验证（教训：fanbao 涨幅过滤、10 点纪律误读）
3. 参数只允许区间调整 + 样本外复核（承重参数：max_pct=3%、动量 60-120%）
4. 上线判定 = 两年样本外正期望 + 案例回归全绿 + 评审通过 + 模拟盘灰度 1 个月
