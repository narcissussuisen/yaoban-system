## 二、结论（如实）
1. **机械管线无前视口径的期望收敛于 0.89~0.92×**：六组组合层/选择层变体（骑乘/集中度/板块热度/k=1/gate/组合）无一改变负期望本质，最优与基线仅差 +0.03×。
2. **评审独立量化确认层无筛选力**（第二轮评审 §Gate④）：watch 候选基线 +3d **-1.42%**/+5d **-2.00%**，确认买入 +3d **-1.98%**/+5d **-2.80%**——**瓶颈在选股层候选池本身**（huigui-v5 信号 3/5 日负漂移），确认引擎既不筛选也不损伤。
2. **裁决线 ≥3× 明确未达标**（最佳 0.92× = 选手 6.4× 的 14%）。
3. **差距的本质**：选手 6.4× 的核心是**人工选股与盘中判断**（圣阳 7 连板单票暴击、主线预判提前埋伏、分时盘感执行）——这些在无前视机械化下不可复刻；机械层能提供的是**高保真信号+严格风控**（回撤可控、无前视、可审计），而非超额选股 alpha。
4. 前视修复（k≥1）后所有正收益消失——此前 1.51×/1.47× 均不成立（评审已确认）。
