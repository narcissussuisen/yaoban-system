## 2. 循环步骤（每次模式迭代都走完整圈）

1. **模式定义**：从语料原文提炼规则 → 写成确定性伪代码（信号日/执行日/持仓期/卖出）
2. **数据支撑**：确认所需数据存在（分钟/日线/情绪/Level2），缺失则补数据管线
3. **回测验证**：scripts/backtest_*.py 全市场样本外跑 2025 + 2026，成本足额
   - 必须：前视偏差检查（shift 正确性）、幸存者偏差（全市场含退市）、
     涨停买不进建模（一字板剔除）、T+1 约束、佣金 0.025%×2 + 印花 0.05% + 滑点 0.1%
4. **专家评审**：每阶段末启动量化专家 subagent，按 docs/reviews/_TEMPLATE.md
   评审，产出 docs/reviews/r{N}_review.md，结论三档 ✅/⚠️/❌
5. **基线固化**：评审通过（或 ⚠️ 整改后）→ 把参数/规则写入 src/core 或候选池脚本，
   git commit 打基线标签
6. **模拟盘跟踪**：portfolio_sim.py 双票 50%×2 口径，与实盘候选同步跟踪
7. **迭代优化**：新发现（如 R7 恐慌衰竭低吸假设）作为新模式进入下一轮循环

## 3. 验收标准（用户拍板，不可放松）

- 两年（2025 + 2026）全市场样本外均正期望（净收益）
- 胜率 ≥ 50%（高胜率 + 高盈亏比模式）
- 任一条件不满足 → 该模式记为"复刻失败"并留档（诚实记录负结果）
