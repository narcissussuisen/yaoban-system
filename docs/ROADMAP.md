```

        ↓

        ↓

```

## 自迭代闭环（核心设计）

```
信号 → 模拟盘执行 → 交易日志 → 周绩效（胜率/盈亏比/回撤/执行偏差）
        ↓                          ↓
  参数漂移检测（月）          规则版本提案（v4.x）
        ↓                          ↓
  网格搜索 + walk-forward   新视频 OCR → 规则草稿（季）
        ↓                          ↓
  护栏（样本外验证+成本建模）→ 灰度（模拟盘1月）→ 合入 bump 版本
```

**护栏原则**
1. 一切参数变更必须通过样本外（walk-forward）验证；
2. 参数只允许**区间**调整，禁止单点魔改；
3. 模拟盘与回测环境分离；版本可一键回滚；
4. 实盘决策始终由人执行（本系统不产生任何自动下单）。

## 技术选型

- Python 3.13（stdlib：tomllib/sqlite3）+ pandas/numpy + akshare（`../py_libs`，--target 安装）
- 存储：SQLite 单文件 `data/yaoban.db`；报告：复用 v4.0 的 md2html 转换器
- 调度：Windows 任务计划（每日 15:30 盘后 / 每周六绩效 / 每月 1 日优化）
- 版本：git（本仓库），规则版本号独立于代码版本号

## 风险登记

| 风险 | 影响 | 缓解 |
|---|---|---|
| akshare 接口限流/断连（已实测） | 采集失败 | 重试+指数退避+缓存+多源备份 |
| py_libs 在普通沙箱模式下不可读 | 数据任务无法运行 | 数据任务以完整权限运行（沙箱特性，README 已注明） |
| 过拟合（参数多、样本少） | 实盘失效 | walk-forward + 成本建模 + 参数高原 + 最小信号量 |
| 涨停池历史数据缺失 | 环境打分五维不全 | 每日增量积累 + 简版打分过渡（已验证方向有效） |
| 视频方法论更新 | 规则过时 | 季末 OCR → 规则草稿 → 回测 → 合入/否决流程 |
