## 选手模式全景（复刻蓝本）

选手每日流程（B篇SOP）：
- 盘前：外围新闻 → 早安观点（指数点位/主线/板块节奏）→ 9:20 竞价初筛
- 9:30：战法筛选 3-4 只（马前炮发布）
- 盘中：分时/均价线/封单盯盘 → B点确认买入 → 动态卖出管理 → 做T
- 盘后：复盘视频 + 次日策略

**七层模式要素**（复刻目标）：
| 层 | 选手规则（证据） | 量化组件 |
|---|---|---|
| ① 选股 | 上升回档5条（均线多头+放量上涨+缩量回档3-5天5-15%+支撑止跌+资金不撤）；涨停回踩5口诀；仙人指路（公式已有）；趋势反包；超跌反弹 | 选股检测器（已有雏形，需对齐+补资金流） |
| ② 买点 | 次日放量阳线突破小高点；分时放量突破均价线回踩站稳≤3%；开盘走弱放弃；抄底4规则（下跌节奏买入） | B点确认引擎（intraday.py 雏形） |
| ③ 卖出 | 12种动态触发（有赚就走/不板10点走/破5减半/破10清/破均价线/龙头炸板联动/封单减少/乖离率/KDJ死叉/-5%低开/板块退潮/逻辑消失） | 卖出引擎（sell.py 已有 60%） |
| ④ 仓位 | 动态 20%-99.8%（弱市降仓、强市满仓）；单吊/2-5只并行 | 环境分→仓位档（env_score 雏形） |
| ⑤ 做T | 正T/反T 1/3仓差价1-3点（均价线引力） | T引擎（sell.py 已有） |
| ⑥ 板块 | 三信号（钱往哪流/核心逻辑/业绩跟上）；龙头识别（启动强度/资金认可度/带动性） | 板块资金流（需L2或代理） |
| ⑦ 情绪 | 情绪温度计（炸板率/连板率/涨停家数/短线情绪℃）；冰点抄底（4000点黄金坑） | 情绪模块（sentiment CSV 已有） |
