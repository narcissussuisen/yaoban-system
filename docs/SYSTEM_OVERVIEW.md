## 三、关键工程事实（防止回归）

- **止损口径铁律**：判定用 LOW(r[4]) 非 HIGH(r[3])；触发日按开盘价成交（跳空）非止损价
- **情绪/因子信号日铁律**：信号日 T 收盘已知 → T+1 执行；任何执行日信息做开盘决策 = 前视
- **执行口径铁律**：判定信息截止时刻 = 成交时刻（W2 教训）
- 数据源：F 盘日线止于 8/21；TDX 日线回填库已验证 0 差异（259 重叠日）；TDX 分钟单位不一致暂缓
- 定时器：UTF-16 XML 注册 + GBK cmd runner（中文路径编码已修复）
- 数据积累：P1 需 tick ≥20 交易日（约 9 月底，loop_engine 自动触发）
