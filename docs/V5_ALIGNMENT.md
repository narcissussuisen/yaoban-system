- 每个阶段：实施 → 自验（脚本跑通+自测通过）→ 提交 agent 评审（loop_engine 生成评审任务）→ 评审通过 → 更新 state → 下一阶段
- 评审通过标准按 #1；评审不通过 → 整改 → 复审（最多变体迭代一次后标记 blocked 上报用户）
