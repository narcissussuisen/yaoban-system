# R3' 卖出层第二轮：龙头联动/板块退潮组合级接口设计

## 已实现（第一轮）
- 乖离率止盈（bias_take）：盘中冲高回落+乖离>=8% 减半（v09 证据）
- KDJ 死叉止损（kdj_death）：日线级 K 下穿 D 清仓（密尔克卫案例）
- 参数：bias_take_pct=8.0 / bias_take_frac=0.5 / kdj_death_stop=True
- 占位参数：dragon_link_sell / sector_retreat_sell（组合级实现）

## 组合级接口设计（下一轮实现）

### 龙头炸板联动（dragon_link_sell）
输入: 持仓股 + 其板块龙头（自动识别：板块内最早涨停+封单最强/最高连板）
触发: 龙头当日炸板（触及涨停后回落>0.5%）→ 持仓跟风股按 vwap 价减半/清仓
证据: 8/26 百花医药「龙头炸板，有赚就走」; 7/2 辽宁能源「豫能控股冲高回落→先出来」

### 板块退潮先行（sector_retreat_sell）
输入: 持仓股 + 其申万行业指数当日分时
触发: 行业指数分时跌破均价线且跌幅>阈值 → 持仓先减仓
证据: 7/10「风格强分歧日，主力从老主线撤」→ 华微反复炸板止盈

## 数据需求
- 龙头识别：板块内个股涨停时间/封单强度（分钟线可算涨停时间；封单强度需 L2）
- 板块分时：申万行业指数分时（F 盘有行业归属；成分股分钟聚合）
