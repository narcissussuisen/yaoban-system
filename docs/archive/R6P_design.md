## 二、组合级回测规格（scripts/r6p_replication.py，新脚本）
- 数据：QFQStore('2026') 分钟+日线；sentiment_full_2026.csv；index_daily；concepts.json
- 窗口：2026-04-01 ~ 2026-08-21（F盘覆盖；8/22 后待回填）
- 每日流程：盘后扫描（并行 workers）→ 备选名单 → 次日盘中按三引擎事件驱动买入 → 逐日持仓管理
- 资金：起点 5W（对标选手）；等权分配备选（≤4 只 × 仓位档）；满仓约束 = 温度计 cap
- 成本：佣金 0.025% 双边 + 印花税 0.05% 卖 + 滑点 0.1% 单边；T+1 约束（当日买不可卖）
- 成交口径：买入 = 确认价 + 滑点；卖出 = 触发价（龙头联动按信号下一根执行——R3' 评审接线期整改项）
- 输出：逐日净值/仓位/持仓明细；月度收益与回撤；与选手资金曲线逐点对照表（4/21、6/18、7/6、7/17、8/13 锚点）
