## 二、Gate ①b/②a：**新增发现——--require-gate 实现缺陷（C8/C9 实验语义不成立）**

### 2.1 代码审计：gate 条件使用泄漏的循环变量 w，而非当前候选属性 ❌

r6p_replication.py:237-240：

    if args.require_gate:
        # 信号日 yang & brk5 硬条件（w[2]=yang, w[3]=brk5, 来自信号日属性=已知）
        if w[2] != 'True' or w[3] != 'True':
            continue

买循环（:229）解包当前候选为 (sym, sd, yang, brk5, buy_yang, buy_vol_up)——**当前候选的 yang/brk5 已就绪，但 gate 未使用**；`w` 是 :209 去重循环 `for w in watch: seen[w[0]] = w` 泄漏的循环变量，循环结束后绑定到**去重前 watch 列表的最后一条元组**（= 窗口最旧信号日候选表按 CSV 行序的最后一条、经持仓/冷却过滤）。Python 语义已实测确认（循环变量泄漏到函数作用域）。

**机制**：gate 变成**日级开关**——若该「任意末行」元组 (yang, brk5)=(True,True)，当日全部候选放行；否则当日全部候选拒绝。与当日任一候选自身的 (yang, brk5) 无关。

### 2.2 实证佐证（交付 fills + 候选表离线核验）

- **候选池构成**：16,305 候选行中 (yang=True & brk5=True) 占 49.7%；按信号日均值 46.7%（min 16.7%）——gate 并非空转条件。
- **top-4 排序后构成**：(brk5, yang) 降序 top-4 在 97/97 日全部为双 True（无持仓/冷却近似）——**若按申报语义（逐候选硬 gate），gate 对 top-4 近乎 no-op**；修正后的 C8 预期 ≈ base（0.89×）。
- **交付 C8 实际行为 = 日级开关特征**：83 笔初始建仓分布在 41 个买入日（base 110 笔/75 日）；出现 base 从未有的单日 4 买（满仓日 4 个）；40 个 base 买入日在 C8 无任何买入（整日拒绝）；另有 10 个 C8 买入日不在 base（组合路径分叉）。离线溯源 83/83 笔候选自身均双 True（top-4 恒双 True 所致，无法区分两种 gate；但日级开关特征与逐候选语义不可调和）。
- **结论**：C8（0.92×）与 C9（0.82×）数字可复现，但**不是**「信号日 yang&brk5 硬条件逐候选过滤」实验的结果；实为「窗口最旧信号日候选表末行的 (yang,brk5) 作日级开关」的伪条件结果。

**仪器化复跑实证（scripts/_r6p_review3_gate_probe.py --gate-mode leak，净值与交付 C8 逐字节一致）**：
- 决策日志 199 条（83 buy / 116 blocked）：**116 条候选自身 (yang,brk5)=(True,True) 却被 gate 拒绝（分布在 40 个交易日）**——即「本可通过申报语义 gate 的候选被日级开关整日拒绝」；
- watch top-4 全窗口 97 日**无一条**非双 True——逐候选 gate 对 top-4 是**完全空转**（修正版预期 ≈ base）；
- 被拒候选与买入候选均与泄漏末行属性无关（买/拒由日级开关决定）——**C8 的 0.92× 是「窗口最旧信号日候选表末行 (yang,brk5) 作日级开关」的结果，与申报的逐候选硬 gate 语义无关**。

### 2.3 对终局结论的影响：方向不变，证据链降级

- **修正版复跑（--gate-mode own，逐候选 (yang,brk5) 硬条件）：期末 44,568.77 = 0.89×，与 v2 base 逐字节一致（净值+577 fills 全同）——逐候选 gate 对 top-4 完全空转（no-op）实证成立**；申报的 C8 0.92× 与 base 0.89× 之差（+0.033）全部来自泄漏 w 日级开关的伪条件，非任何 gate 筛选收益；
- 修正后最优仍 0.92×（C2），**裁决线 ≥3× 依然明确未达标**；
- 负期望收敛、候选池负漂移（第二轮独立量化 -1.42%/-2.00%）、人工盘感不可机械化等结论**不依赖 C8/C9**，成立性不受影响；
