# 量化专家评审模板（R2 机制）

> 用法：每阶段末，以量化专家角色（subagent）对阶段交付物评审，按本模板填写，
> 存入 docs/reviews/{stage}_{date}.md。结论三档：✅ 通过 / ⚠️ 有条件通过（列整改项）/ ❌ 不通过。

## 评审对象
- 阶段：{stage}（{title}）
- 交付物：{artifacts}
- 数据/样本：{data_desc}

## 一、方法严谨性审查

| 检查项 | 结论 | 说明 |
|---|---|---|
| 前视偏差（未来信息泄漏） | | 信号日/执行日时序、因子用当日可用信息（shift 正确性） |
| 幸存者偏差 | | 标的池是否含退市/停牌；代码变更处理 |
| 成本口径 | | 佣金/印花/滑点是否足额；T+1 约束；涨停买不进 |
| 参数过拟合 | | 参数网格高原 vs 尖峰；是否多参数联合调优 |
| 样本外一致性 | | 2025/2026 独立验证；分月稳健性 |
| 统计显著性 | | n 是否足够；胜率/均值置信区间 |

## 二、结论与数据一致性
- 关键数字复算（如抽样核对 10 笔交易明细）
- 与既有结论的兼容性（动量池/情绪/选股池分层）
