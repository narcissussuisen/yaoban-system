# R6' 阶段诊断评审意见

**结论：条件性成立**——R6' 未达标、差距在选股层方向正确，但核心论据有实质缺陷，不足以裁定"选股层无判别力"。

**① 逻辑漏洞**：a) r20 用买入日收盘+20日盲持，与选手"回档低吸+逢强止盈+让赢家跑"不符；锚股实际收益多正（中位 +6.16%、胜率≈93%），与 r20 中位 -9.1%/胜率29% 严重背离，该背离恰证明选手边际来自活跃择时退出而非选股。"选股无平均 alpha"是误断。b) 右尾归因自相矛盾：诊断称 6.4× 由百合花+122%/太极+94% 驱动，但锚股表显示选手实际仅 +8.18%/+6.74%——那是20日盲持收益，选手未吃到（+8%/+6.7%即止盈）。c) 锚股为72视频OCR"展示交易"子集（约70笔/52只），非完整流水，有未量化幸存偏差，93%胜率偏高于真实。d) yang88%vs77% 实为锚股方向一致更高，应为"弱判别"而非"无判别"；且这些特征≠选手战法（上升回档/趋势反包等），系统从未实现选手真实选股，属"实现缺口"非"能力缺口"。

**② 机械层**："≤0.93×无边际"仅在给定当前缺陷选股层下成立。低估杠杆：入场价格（圣阳17.77vs15.05差18%，与"差异不在入场时刻"冲突，18%价差足以吞掉+6%边际）、确认后集中赢家（E3差因选股差时集中放大亏损）、骑乘未验证是否吃满圣阳7连板、做T层未充分体现。

**③ 路径排序**：b题材催化驱动（concepts.json可机械实现、低成本增量）≻ a选手实盘资料（定位选股前因、依赖外生）≻ c降线1.5×（快但放弃选股定位，仅在a/b证实含不可机械化盘感时启用）。

**④ 处置**：维持阻塞/未达标，但应按"实现缺口"而非"能力缺口"存档；以 b+a 推进选股层，若修正后候选池3/5日漂移仍负且无新判别特征，才降线至1.5×过渡。
