## 四、gate 判定

**评审补测：零假设 bootstrap**——对每只锚在其同期内随机抽取日期测 6 日窗口命中率：**零假设覆盖率 = 23.4%**（信号密度 8.4%/日，聚集效应使 iid 估计 40% 偏高）。实际 52.4% 相对零假设 z≈4.4σ，**显著高于随机**；且 19/22 命中为 k≤1（信号在买入日或前一日），与"止跌→买入"机制吻合。→ **方向性结论成立：检测器行为与选手证据显著一致（非凑数）。**

**但 52% 未达自评目标 70%，且存在口径膨胀**：清洗分母（剔除确认非回档锚 意华/长电/证通/腾龙）后 ≈ 55~58%；严格 k≤1 口径仅 45%。加上 1.5%/0.9 无证据、圣阳归因错误，**当前数字不足以直接放行 gate**。

**建议 gate 定义（四条件并置，R1' 组件一致性）**：
1. 清洗后分母（剔除有视频证据的非回档锚）覆盖率 **≥ 60~65%**；
2. 严格口径 k≤1 覆盖率 **≥ 45~50%**（并报告 k 分布）；
3. 覆盖率 ≥ **2× 个股同期 bootstrap 零假设**（当前 2.2×，勉强达标）；
4. 参数来源书面化：1.5%/0.9 必须有选手视频出处，否则只能以敏感性平台区取值。

**整改项（复审前闭合）**：
- [ ] R1.1 验证脚本改取窗口内**最接近买入日**的信号并输出 k 分布；圣阳归因改为"4/7 当日信号（MA20 0.27% 回踩+低开高走+红肥绿瘦 0.93）"；
- [ ] R1.2 锚名单审计：42 只逐只确认建仓日（买入价落区间，已抽查 9/9）+ 战法标签与锚文档统一单源（埃斯顿/金牛/证通/腾龙/意华归类定案，四川黄金/恒宝/百花/华微7-9/太极8-13 补入或书面排除）；
