# R1 阶段研究结论独立评审报告（妖板交易系统）

> 评审人：量化专家 agent · 日期：2026-08-25 · 结论：⚠️ 有条件通过

## 总体结论
"回踩形态池 + 开盘执行"两年大样本正期望（2026 +0.49%/3811 笔、2025 +0.66%/7100 笔）方向一致，证据链中最扎实，可作为选股池进入下一阶段；但网格搜索零样本外验证、B2 结论缺成交建模支撑、胜率门槛与 A 股短线收益结构不匹配。放行前提是闭合整改项。

## 方法严谨性审查要点
1. **时序/前视**：形态因子 T 日收盘构造、T+1 执行方向合规；需固化①MA20 含 T 日收盘、②D 组合"次日低开"=T+1 开盘（9:25 已知）语义、③涨停按板块分口径（10/20/30%）。
2. **成本**：往返约 0.30%，须标 gross/net；**B2 限价单未成交问题**——只统计已成交样本会剔除"未回到触发价"的强势信号，策略级期望须含 fill-rate 建模。
3. **幸存者偏差**：需确认退市股保留至退市日、前复权按时序、ST/新股按上市时点纳入。
4. **网格过拟合**：2026 样本内枚举 11 达标→2025 全灭，是样本内挑参的预期表现；正确流程=2026 固定参数→2025 独立验证+报告全分布。
5. **显著性**：2026 D 组 116 笔 54% 胜率≈0.9σ（等于 50%）；n<100 应标注"探索性"；按股票聚类。

## 结论评估
- a) 回踩形态池选股（开盘执行两年正期望）：✅ 有条件可信（右偏低胜率结构，非高胜率）
- b) B2 低吸无法复刻：对已测变体成立，但结论被高估——未测变体（fill-rate、真低吸占比、卖出规则变体、动态触发/R7 level2 承接）应列为开放项
- c) **胜率≥50% 门槛不合理**：A 股短线 45-50% 胜率+盈亏比>1 是常态盈利结构；116 笔 54% 统计上等于 50%。建议：
  - 硬门槛：两年样本外净期望>0 + 按股票聚类 t 检验显著
  - 补充门槛（任选）：盈亏比≥1.2 / 月度正收益占比≥60% / 夏普≥1.0 / 回撤可控
  - 胜率降为参考指标（综合≥48% 可参考），强制报告每笔期望/盈亏比/月度分布三件套
