# R4' 仓位层第一轮：选手仓位锚 vs 环境分档位验证（诚实负结果）

> 日期：2026-08-26 · 状态：待评审

## 一、验证设计
- 选手仓位轨迹（GAP_FINAL）：99.8%(4/21) → 69.3%(6/18) → 34.8%(7/6) → 20%(7/17 至暗) → 51.2%(8/13)
- 引擎：env_score 简版（上证指数 trend+volume）/ 四维（+涨停数 zt+连板高度 max_h），regime → position_cap（strong 70/neutral 50/weak 20）
- 数据：yaoban.db index_daily（sh000001，155 行至 8/24）+ outputs/sentiment_daily_2026.csv
- 脚本：scripts/r4p_env_anchor.py

| 日期 | 选手仓位 | 简版分 | 简版档 | 四维分 | 四维档 | zt | 炸板率 | max_h | 判定 |

**方向匹配仅 1/5（7/17）**。指数趋势+量能的环境分不能解释选手仓位档。

## 三、归因（数据支持）
1. **选手仓位由情绪质量驱动，非指数趋势**：4/21 指数弱势（简版3分）但选手 99.8% 满仓——当日炸板率 23.1% 为五锚最低（封板质量最高）+ 连板高度 4 + 自身持仓大幅浮盈（圣阳 7 连板为 4/9~4/17，4/21 圣阳 -10.02% 跌停——评审更正时点）；7/17 至暗 zt=35+炸板44.4%+高度3 → 20% 最低仓。
2. **炸板率是候选主导变量**：仓位排序（99.8 > 69.3 > 51.2 > 34.8 > 20）与炸板率排序（23.1 < 37.3 < 44.3 ≈ 44.0 < 44.4）几乎完全反向对应——n=5 不做回归，仅作为 R5'（情绪板块层）合成方向假设。
3. **选手仓位弹性超引擎 cap**：强市选手 90%+，引擎 strong cap=70（parameters.toml）——对齐缺口，待情绪质量分合成后改。

## 四、结论与设计变更提案（待评审批准）
- R4' 仓位档驱动变量从「指数趋势+量能」改为「情绪质量分」（zt 数 + 炸板率 + 连板高度合成，R5' 交付）为主、指数趋势为次确认；
- position_cap 档位对齐选手：strong 90 / neutral 50 / weak 20；
- 量能 2.5 万亿门槛（8/26 证据）：index_daily 无 amount 列，两市成交额数据缺口 → 需从涨停池行情接口补（随 tick 积累管线一并解决）；
- 选手自身浮盈状态（「赚到钱了敢上仓位」）暂不纳入机械模型，如实声明为不可复刻维度。
